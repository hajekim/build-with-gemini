Step 0

개요 및 엔터프라이즈 에이전트 아키텍처

임직원의 일상 업무에서 발생하는 인사 복무(휴가/병가) 신청 및 IT 장비 고장/교체 문의를 사내 규정(PDF)과 실시간 연계하여 자동화하는 AI 에이전트를 구축합니다.

실습 1 핵심 목표
  • Google Antigravity 2.0 (agy) 대화형 프롬프트 주도 개발
  • Google ADK 2.0 (google-adk) 기반 멀티 툴 에이전트 구축
  • Cloud Storage 규정 PDF 기반 시맨틱 RAG 검색 도구 구현
  • FastMCP 프로토콜을 통한 Korean Mock SaaS 연동 및 테넌트 격리
실습 2 연계 (Next Step)

실습 1에서 개발한 에이전트를 바탕으로, 실습 2에서는 Model Garden 보안 가드레일, Agent Gateway 연동, Zero-Trust 보안 및 Gemini Enterprise 배포용 A2A(Agent-to-Agent) 구성을 완성합니다.

터미널 환경 세팅 안내: 실습 터미널에서 다음 명령어로 실습 에셋을 즉시 복제하여 시작하세요:
git clone https://github.com/hajekim/build-with-gemini.git
Step 1

Qwiklabs 실습 시작 및 Google Cloud 콘솔 로그인

실습 플랫폼(Qwiklabs / Cloud Skills Boost)에서 임시 자격증명을 발급받고 시크릿 브라우저 창으로 Google Cloud 콘솔에 안전하게 접속합니다.

시작 전 필수 주의사항:

1. 실습 시간은 정해져 있으며 일시 정지할 수 없습니다. Start Lab 버튼을 클릭하면 타이머가 즉시 시작됩니다.

2. 반드시 Chrome 시크릿 창(Incognito Window)을 사용하세요. 개인 구글 계정과 세션이 섞여 불필요한 개인 과금이 발생하는 것을 방지할 수 있습니다.

3. 개인 프로젝트나 회사 계정이 아닌, 실습 패널에서 제공된 임시 자격증명만 사용해야 합니다.

1 Start Lab 클릭 및 임시 자격증명 확인

실습 페이지 좌측 상단의 Start Lab 버튼을 클릭합니다. 약 1~2분 후 왼쪽 Lab Details 패널에 임시 자격증명이 표시됩니다:

Username: student-01-xxxx@qwiklabs.net
Password: **********
GCP Project ID: qwiklabs-gcp-01-xxxx

2 Google Cloud 콘솔 접속 (시크릿 창)

Open Google Cloud console 버튼을 마우스 우클릭한 뒤 시크릿 창에서 링크 열기(Open Link in Incognito Window)를 선택합니다.

• 계정 입력 창이 열리면 복사한 Username을 붙여넣고 [Next]를 클릭합니다.
• 비밀번호 창에 복사한 Password를 붙여넣고 [Next]를 클릭합니다.
• 이용약관 및 서비스 조건에 동의합니다. (복구 옵션이나 2단계 인증 설정은 건너뜁니다.)

3 Google Cloud 콘솔 진입 완료

콘솔 상단 타이틀 바에 표시된 프로젝트 ID가 실습 패널의 GCP Project ID와 일치하는지 확인합니다. 이제 실습 전용 원격 환경으로 접속할 준비가 완료되었습니다.

Step 2

원격 실습 환경 접속 및 Antigravity CLI (agy) 설정

Cloud Run 프록시로 제공되는 원격 브라우저 세션에 접속하여 Konsole 터미널을 열고, Antigravity CLI를 초기화합니다.

1 원격 데스크톱 세션 접속 (Cloud Run Proxy)

Google Cloud 콘솔 상단 검색창에 Cloud Run을 검색하여 클릭한 뒤, 서비스 목록에서 remote-browser-vm1을 클릭합니다.

서비스 세부정보 페이지에 표시된 URL 링크를 새 탭으로 열어 원격 브라우저 세션에 접속합니다. 브라우저가 클립보드 접근 권한을 요청하면 허용(Allow)을 클릭합니다.

클립보드 매니저 팁: 로컬 PC와 원격 세션 간 텍스트 복사가 원활하지 않은 경우, 원격 화면 우측 하단의 [Clipboard] 아이콘을 열어 텍스트를 붙여넣은 뒤 닫으면 터미널에 정상 붙여넣기가 가능합니다.

2 Konsole 터미널 실행 및 agy 초기화

원격 데스크톱 화면 좌측 하단의 Application Launcher > System > Konsole을 클릭하여 터미널을 열고 다음 명령어를 입력합니다: 

agy
• 로그인 방식 선택: Use a Google Cloud project 선택
• 브라우저 창에서 계정 선택 후 발급된 인증 코드를 터미널에 붙여넣기
• Project ID 선택: 본인의 qwiklabs-gcp-01-xxxx 선택
• Location 설정: global 입력
• 테마 선택: 선호하는 색상 테마 선택 후 [Next]
• 폴더 신뢰 알림: Yes, I trust this folder 선택 후 Enter

3 주력 모델 설정 (Gemini 3.8 Flash)

agy 대화창에서 /model 명령어를 입력하고 gemini-3.8-flash를 선택합니다: 

/model

실습 환경에는 Gemini 3.8 Flash 모델에 프로비저닝된 처리량이 활성화되어 있어 빠른 응답 속도를 보장합니다.
